# Responsive Website Project

This is a fully responsive website built using HTML5 , CSS3 and Bootstrap5.  
The design is optimized for all devices including mobile, tablet, and desktop screens.

The project demonstrates modern web design principles such as responsive layout, clean UI, and user-friendly navigation.

## Features
-  Fully Responsive Design (Mobile, Tablet, Desktop)
-  Clean and Modern UI
-  Fast Loading Performance
-  Smooth Navigation
-  Cross-browser Compatible

## Technologies Used
- HTML5
- CSS3
- Bootstrap5
- JQuery Plaguin
- Bootstrap Carosul
- Google Fonts
- Font Awesome
